PUBLICAR EN GITHUB PAGES
------------------------
1. Descomprime el ZIP.
2. Sube index.html, styles.css y la carpeta assets a tu repositorio.
3. Ve a Settings > Pages.
4. En Source elige Deploy from a branch.
5. Selecciona main y /root.
6. Guarda y espera a que GitHub genere el enlace.

Dentro de index.html busca:
https://TU-USUARIO.github.io/blog-etica-daniel/

Reemplázalo por la URL real de GitHub Pages.
